# Sajj Consulting website

A responsive Next.js website for Sajj Consulting, covering specialist IT and digital recruitment services, live roles, job-seeker guidance, hiring insights and enquiries.

## Local development

```bash
npm install
npm run dev
```

Open the local address printed by Next.js.

## Quality checks

```bash
npm run lint
npm run build
```

## Main routes

- `/`
- `/about`
- `/services`
- `/job-seekers`
- `/jobs`
- `/insights`
- `/contact`

## Deployment

The production target is Hostinger. Deployment settings and environment variables should be configured for the selected Hostinger hosting plan before the first release.
